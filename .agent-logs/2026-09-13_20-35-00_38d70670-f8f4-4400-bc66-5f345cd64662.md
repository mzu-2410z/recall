2. **PostgreSQL Date Parsing Error on Action Item Persistence**: The `action_items` table column `deadline` in Supabase is of PostgreSQL type `DATE`. 3. **Markdown Fence JSON Parsing Failure**: Groq LLM responses wrapped in markdown code fence blocks (` ```json { ... } ``` `) caused standard `JSON.parse` to fail with `SyntaxError: Unexpected token '`'`, falling back to empty summaries (`Summary unavailable`).
