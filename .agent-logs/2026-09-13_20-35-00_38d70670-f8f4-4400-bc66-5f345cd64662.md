### 1. Exact AI Root Cause
1. **Model Decommissioning & Availability**: Groq decommissioned `llama-3.1-70b-versatile` and `llama3-70b-8192` (HTTP 400), while `llama-3.3-70b-versatile` returned HTTP 404 (`model_not_found` / not accessible on this account tier), causing all Groq API completion requests to throw exceptions.
2. **PostgreSQL Date Parsing Error on Action Item Persistence**: The `action_items` table column `deadline` in Supabase is of PostgreSQL type `DATE`. Free-text strings returned by LLM (e.g. `"next Friday"`, `"by Wednesday"`, `"Tuesday"`) caused PostgreSQL `22007 invalid input syntax for type date` errors during database insertion, causing HTTP 500 exceptions in `/api/meetings/[id]/summarize` and `/api/youtube/process`.
3. **Markdown Fence JSON Parsing Failure**: Groq LLM responses wrapped in markdown code fence blocks (` ```json { ... } ``` `) caused standard `JSON.parse` to fail with `SyntaxError: Unexpected token '`'`, falling back to empty summaries (`Summary unavailable`).
